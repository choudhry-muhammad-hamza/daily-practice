Q : what is table in html ?

Ans : tables are used to represent table data in html.

    elements :

  • td : td stand for table data.it is used to display table data.
  • tr : tr stand for tablr row.it is used to display table row.
  • th : th stand for table header.it is used to display table header.
  • caption : to display table caption.
  • thead : to wrap table head.
  • tbody : to wrap table body.
  • colspan : used with th to define the number of columns which header takes.
  • border : used with table to specify table border.
